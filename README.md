**TokPulse** is a modern, immersive short-video social application built with Kotlin and Jetpack Compose. Inspired by TikTok, it offers smooth vertical video scrolling, creator profiles, live streams, sound discovery, video recording & upload, interactive comments, and a full administration moderation dashboard.

## 🌟 Key Features

### 1. 🎥 Immersive Vertical Video Feed
- High-performance full-screen vertical swipe video player with seamless loop playback.
- Dynamic like animations, comment sheets, interactive share sheet, and profile navigation.
- Story row at the top with live creator stories.

### 2. 📹 Video Creation & Camera
- In-app video recording and camera capture with sound selection.
- Video preview, caption input, hashtags, and instant cloud upload to Firebase Storage.

### 3. 💬 Real-Time Interactions & Chat
- Instant comments with nested replies.
- Direct messaging (DM) between users.
- Live stream previews with interactive chat and floating hearts.

### 4. 👤 Creator Profiles & Discovery
- Detailed user profiles displaying follower/following counts, bio, uploaded videos, and liked clips.
- Trending hashtag and sound discovery screen.

### 5. 🛡️ Comprehensive Admin Moderation Dashboard
- Dedicated admin portal for content moderation, flagged report reviews, and user management.
- Privacy compliance & GDPR user data management centers.

## 🛠️ Tech Stack & Architecture

- **Language:** Kotlin 2.2.10
- **UI Framework:** Jetpack Compose + Material Design 3
- **Architecture:** Clean MVVM with StateFlow & Coroutines
- **Backend Services:**
  - **Firebase Authentication:** Secure email/password and Google Sign-in.
  - **Cloud Firestore:** Real-time social feed, comments, and profile data.
  - **Firebase Cloud Storage:** Video and avatar media hosting.
- **Local Persistence:** Room Database 2.7.0 + KSP
- **Media & Images:** Coil Compose & Android Media Framework
- **Signing:** Official 30-year Production RSA Certificate with APK Signature Schemes v2/v3
