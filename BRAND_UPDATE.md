# ZEVORA brand update

- Display name is standardized as ZEVORA.
- New neon crown/play ZEVORA logo added as the Android launcher icon.
- Android launcher raster assets updated for mdpi through xxxhdpi.
- Adaptive v26 launcher XML overlays were removed so the new raster icon is used consistently.
- Android in-app brand mark now uses the same ZEVORA icon and wordmark.
- Web title, metadata, and visible brand labels updated to ZEVORA.
- Package name, Firebase configuration, backend/API URLs, GitHub repository URLs, storage keys, and internal class names were intentionally left unchanged to avoid breaking the existing integrations.
- Release download URLs remain pointed at the existing repository artifacts until a release is rebuilt under a new filename.
